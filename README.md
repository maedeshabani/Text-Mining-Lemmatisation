# Text-Mining-Lemmatisation
This repository showcases our collaborative work on developing a French Lemmatizer as part of the Text-mining & Chatbots course, taught by Professor Thomas Gerald at Paris-Saclay University.

We explored three primary strategies to achieve this goal:

01 : Dictionary-Based Approach
Leveraging a predefined dictionary for lemmatization.

02: Machine Learning Approach
Utilizing Scikit-learn and Keras to build and train machine learning models.

03: Comparison with Pretrained Tools
Evaluating our methods against the performance of spaCy, a widely-used natural language processing library.
